# Safety & Compliance

How xpersonas keeps personas safe and compliant.

---

## Anti-spam safeguards

### Brand mode

| Safeguard | Description |
|-----------|-------------|
| **Frequency caps** | Max product mentions per week per product (configurable, default: 3) |
| **Account aging** | Minimum non-promotional posts before any product mentions (configurable, default: 100) |
| **Ratio enforcement** | Product mentions stay under 10% of total activity |
| **Disclosure injection** | Prompt includes FTC disclosure requirements (#ad, #sponsored) |
| **Anti-superlative filter** | Blocks "best ever", "game changer", etc. |
| **Cooldown period** | Default 90 days before any product mentions |
| **Coordination prevention** | Multiple personas can't mention same product in same thread |

### Personal mode

| Safeguard | Description |
|-----------|-------------|
| **Substantive engagement** | LLM evaluates if comment is genuinely helpful, not just flattery |
| **No coordination** | Multiple personas don't engage the same person |

---

## What the platform enforces

1. **Frequency caps**: hard limits on product mentions per week
2. **Ratio enforcement**: product mentions <10% of total activity
3. **Account aging**: minimum age and post count before promo
4. **Disclosure injection**: prompt includes disclosure requirement
5. **Anti-superlative filter**: blocks overly promotional language
6. **Audit trail**: every action logged with reason and score

## What the platform does NOT enforce

1. **Legal compliance**: you are responsible for your own FTC compliance
2. **Platform ToS**: you accept the risk of platform enforcement
3. **Content accuracy**: LLM-generated claims are not verified
4. **Human oversight**: ask mode is optional, not required

## FTC disclosure

### X/Twitter

Include `#ad` or `#sponsored` in promoted posts. The prompt engine injects disclosure requirements when `promo.require_disclosure` is true.

### Reddit

Include "Disclosure: I work with [brand]" in comments. Reddit's 10% rule applies.

### LinkedIn

Include "Ad" or "Partnership" in post body, not just profile.

## Rate limiting

Three layers prevent platform detection:

### Per-cycle limits

Actions per agent cycle (default: 5 likes, 2 replies, 2 reposts, 1 quote).

### Hourly limits

Actions per hour (default: 20 likes, 8 replies, 8 reposts, 4 quotes, 3 follows).

### Daily limits

Actions per day (default: 80 likes, 30 replies, 30 reposts, 15 quotes, 15 follows).

All limits are configurable per persona in `engagement.rate_limits`.

---

## Anti-detection

The browser automation includes human-like behavior:

- **Bezier mouse movement**: cursor follows a curved path with overshoot
- **Character-by-character typing**: replies typed with 50-150ms random delays
- **Random delays**: 3-8 seconds between actions
- **Break logic**: 10-30 minute breaks after scrolling ~2500 posts
- - **Smooth scrolling**: `behavior: smooth`, not instant jumps
- **Auth state persistence**: browser sessions survive restarts

## Audit trail

Every action is logged to `activity_log` with:

| Field | Description |
|-------|-------------|
| `persona_id` | Which persona took the action |
| `action_type` | like, reply, quote, repost, follow |
| `target_post_id` | Post that was engaged with |
| `target_author` | Author of the target post |
| `content` | Text generated by the LLM |
| `score` | Relevance score (0-10) |
| `reason` | LLM's reasoning for the action |
| `success` | Whether the action succeeded |
| `error` | Error message if failed |
| `is_promo` | Whether this was a product mention |
| `product_id` | Which product was mentioned |

### Viewing activity

```bash
# Via CLI
xpersonas agent status --db xpersonas.db

# Via API
curl http://localhost:8000/api/v1/activity/{persona_id}
curl http://localhost:8000/api/v1/activity/{persona_id}/stats
```

## Browser sessions

Each persona gets its own Playwright BrowserContext:

- **Isolated cookies**: personas don't share login state
- **Auth state persistence**: saved to JSON, loaded on startup
- **Session verification**: can check if session is still valid
- **Per-persona user agent**: different browser fingerprints

---

## What you should know

### Platform risks

- **X/Twitter**: Automated interactions can lead to account suspension
- **Reddit**: 10% self-promotion rule is enforced by community moderation
- **LinkedIn**: Disclosure requirements are strict
- **Instagram**: Paid Partnership tag required

### Mitigation

- Start with low rate limits
- Monitor activity closely
- Use human-like behavior (already built in)
- Don't spam: quality over quantity
- Always disclose when promoting products
